# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.3.0](changelog/0.3.x/0.3.0.md) — 2026-10-29

Agent skill served over MCP, include de-duplication before the cut to five, and case-sensitive named character reference decoding

## [0.2.0](changelog/0.2.x/0.2.0.md) — 2026-10-17 · ⚠️ Breaking

Bounded reads and reliable crime search results

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-02

Month ranges with per-month totals on the crime and stop and search searches, typed retryable failures for upstream outages on every tool, force names on every force input, and per-force coverage notes for polygon and location searches.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — six tools over data.police.uk for UK street-level crime, police outcomes, stop and search, and neighbourhood policing teams, with no API key.
