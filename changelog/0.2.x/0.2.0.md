# 0.2.0 — 2026-10-17

## Added

- **Outcome category counts** expose `by_category` across all matched outcomes, independent of paging ([#17](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/17)).

## Changed

- **Crime-history input** is now limited to 1,000 raw elements/tokens and 128,000 UTF-16 code units, including duplicate-heavy or whitespace-padded requests previously accepted ([#16](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/16)).
- **Bounded reads** accept search limits through 10,000 while applying a 200-row cap; histories process 25 unique ids and return ordered `remaining_ids` for continuation.
- **Neighbourhood matching** retries a unique case-insensitive catalog match after an exact miss, echoes canonical ids and reports ambiguous candidates ([#18](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/18)).

## Fixed

- **Coverage notices** disclose failed or timed-out supplemental lookups without discarding search records or claiming unknown coverage is published ([#14](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/14)).
- **Stop outcomes** normalize documented `false` values to `Nothing found`, separately from unrecorded outcomes ([#15](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/15)).
- **Neighbourhood HTML** preserves spaces between table cells in descriptions, priorities and events ([#13](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/13)).
- **Registry launch configuration** uses `npx` and fixes the HTTP transport environment; packaging excludes source and cache files from MCPB bundles and unused musl packages from glibc images. Local tooling, CodeQL categories and framework skill references follow current framework conventions.
