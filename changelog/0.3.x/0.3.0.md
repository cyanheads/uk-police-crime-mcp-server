# 0.3.0 — 2026-10-29

## Added

- **`uk-police-crime-guide` agent skill** served at `skill://uk-police-crime-guide/SKILL.md` (listed by `resources/list`, template `skill://{+path}`) through `createApp({ skills: 'skills' })`, and shipped in the npm package, Docker image and `.mcpb`. It carries the gates for coverage gaps, month ranges, outcome stages, stop and search breakdowns and area comparisons, and the server instructions point to it.

## Changed

- **`ukcrime_search_outcomes`** description, `month` fields, `data_note` and notices say that `month` selects the outcome data data.police.uk published for that month, that each outcome keeps its own `month`, and that a crime's earlier steps can be missing; `ukcrime_search_crimes` says `persistent_id` is present only when a crime has one.
- **`range_incomplete` message** names the earliest month the call did not fetch ("2026-03 is the earliest month it did not fetch") in place of "2026-03 and later did not start".
- **`ambiguous_neighbourhood` message and recovery hint** carry the candidate ids as written (`'[NX]'`), where 0.2.0 pre-escaped them (`'\[NX\]'`); `content[]` escapes them once.
- **Packaging** follows `@cyanheads/mcp-ts-core` ^0.13.18: root `plugin.json` and `mcp.json`, an anchored `.mcpbignore`, a stricter `.mcpb` cleaner, `skills/` copied into the production image, and `minimumReleaseAge` of one day in `bunfig.toml`.

## Fixed

- **`ukcrime_find_neighbourhood` `include`** is de-duplicated before it is cut to five entries, so `["team","team","team","team","team","boundary"]` returns the boundary instead of dropping it ([#21](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/21)). A list that still holds more than four entries after de-duplication, such as `["team","team","team","team","team","invalid"]`, is rejected as InvalidParams; it broke the advertised schema (`maxItems: 4`, enum) and 0.2.0 ignored its unknown value.
- **Named character references** in force-written HTML decode case-sensitively from the full WHATWG list of 2,125 names: `&Eacute;` is `É` and `&ouml;` is `ö`, where 0.2.0 lowercased every name against a 24-entry table ([#22](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/22)). Unknown names, and names that decode to an invisible or control character, stay as written.
- **Range-budget test** in `tests/tools/search-crimes-range.test.ts` no longer depends on which concurrent range wins a pacer slot, which made it fail about 1 run in 10 under Bun (test-only, [#23](https://github.com/cyanheads/uk-police-crime-mcp-server/issues/23)).
